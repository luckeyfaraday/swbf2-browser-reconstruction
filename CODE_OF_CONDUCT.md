# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, assume good faith, and keep discussion about the work. Harassment, insults, discriminatory language, personal attacks, and publishing others' private information are not acceptable in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour to the maintainers by opening a private report through GitHub (the maintainer is [@luckeyfaraday](https://github.com/luckeyfaraday)). Reports are handled confidentially. Maintainers may remove content and restrict or ban participants who violate this code, following the Covenant's enforcement guidelines.
