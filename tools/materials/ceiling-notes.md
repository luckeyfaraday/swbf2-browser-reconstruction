# Original Death Star ceiling material

`LOCAL-CEILING-SHADER-001` recovers `Objects/Architecture/_GalacticEmpire/_Shaders/SS_DSI_Ceiling_01` from retained RVM data. Name hash `1075960127`, shader GUID `8ba99542-9789-9ac3-6bf5-4e197335e9f5`, selected deferred PS `1fb4d25b38`, paired VS `dfb8f760fb`.

The exact default family covers 20 previously neutral sections across 493 placed section instances. Three texture bindings are recovered through the RVM texture-conversion/apply slots and matching low48 serialized parameter keys: ceiling mask t2, metal CS t3, metal normal t4. Five material vectors are recovered through the constant-table writes and section override graph. All 20 sections set UV scale 0.5. Source emission strengths are nine sections at 5000, six at the shader default 15000, four at zero, and one at 3000. A filename containing `nolight` does not zero every section: each exact section override is preserved.

The material uses `q=UV*scale`, `smoothness=2*pow(metalCS(q).g,1.5)`, normal RG from `metalNormal(2q)` with normal-X R*A packing, and mask `saturate(mask(UV).r*1.1111111640930176-0.111111119389534)`. The mask interpolates stored linear base color toward white and multiplies the source emissive color, strength and multiplier. The subsequent [atlas and deferred-consumer recovery](ceiling-static-atlas-notes.md) proves native `o2.y=0.5*metalCS.r` is ordinary-ID0 metalness; the current generated adapter applies that value.

The deferred DXBC adds emission to native prelighting before the same `cb2[40].x` output scale. The browser uses the reconstruction's established linear-radiance scale 1 and common native map exposure. No per-material normalization is introduced. Native runtime values of the global output-scale buffer remain uncaptured. The companion forward PS `ea1d8d1532` explicitly complements clamped source smoothness before its BRDF; the browser maps this to `1-clamp(S,0,1)`.

`ceiling-test.py` compares compact algebra to the existing generic disassembly interpreter without executing the Master1UV test or changing its outputs. It tests 2,000 UV-dependent fixtures, all 20 constant sets, normalized normals, color, smoothness, native scalar, and emission added to randomized prelighting before the shared output scale. Maximum error is `2.22e-16`. This is static arithmetic equivalence, not native execution or float32/FMA bit identity.

`ceiling-prepare.py` adds one 2,090-byte source-mask PNG and reuses two existing source metal texture URLs. DDS mip payload ranges, source formats, source hashes and PNG hashes are retained. No PNG resizing/channel processing occurs. The browser module is generated from `ceiling-adapter.template.js` and `ceiling-equations.glsl`.

Integration: load `/assets/recovered-ceiling-materials.json`, call `prepareRecoveredCeilingMaterials(document,manager)` from `web/src/ceiling-material.js`, and invoke its `apply(gltf,asset)` alongside floor/Master1UV before static batching and probe decoration. `applied` and `provenance` follow the existing adapter API. The adapter retains source UVs, exact constants, raw smoothness and texture-driven metalness. Separate Three emission is zero: source-probes adds emission to atlas or SH prelighting before the DFG/albedo/nonmetal response, including fallback sections without geometric atlas data. Derivative tangent reconstruction remains an approximation until packed source tangents are decoded.

Validation: run `python tools/materials/ceiling-analyze.py`, `python tools/materials/ceiling-test.py`, `python tools/materials/ceiling-prepare.py`, then `node --test test/ceiling-material.test.js` from `web`. The four Node tests verify source identities, all default section constants/bindings, exact native mip payload/PNG hashes, and shader-hook survival through source-probe instrumentation. Root performs the GPU compile and full browser run to avoid concurrent GPU work.
