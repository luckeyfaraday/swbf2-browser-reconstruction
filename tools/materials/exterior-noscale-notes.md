The recovered packed equations are:

```text
B = BaseRGBA(UV0)
D = DetailNA(UV0 * cb0.xy)
color = 2*D.a*mix(cb1.rgb, cb2.rgb, B.a)
response = 2*(1-B.a)*D.a
smoothness = response*cb3.x

AO = B.b
baseTangentNormal = (2*B.rg-1, sqrt(max(1-length(2*B.rg-1)^2,0)))

```

Normal blending is unusual and must preserve coordinates and normalization order. The shader transforms the base and detail tangent normals separately into world space and normalizes each. It adds detail only along source WORLD X/Y: `prelightingNormal=baseWorld+detailWorld*(1,1,0)`. That sum remains unnormalized for SH and broad specular prelighting. Only the final G-buffer normal is normalized. Adding normals in tangent space, masking tangent Z, or renormalizing before SH would produce different source math.

The adapter reconstructs the derivative UV frame in view space, transforms each result back to current source world axes, combines them with the exact world mask, and exposes `bf2_exterior_prelightingNormal` in fragment scope before lighting. It transforms the sum into view space and normalizes only the final Three surface normal. Original packed tangents remain undecoded, so derivative frame parity remains an approximation. The reconstruction currently preserves source world axes; any future world-coordinate conversion must also transform the world mask.

Integration requires the source-probe SH normal expression `bf2_exterior_prelightingNormal`, **without normalization**. This applies to both fallback SH and native DFG diffuse. Marker `material.userData.recoveredExteriorNoScaleShader.nativeLightingInputs` records that requirement and its exact native instructions. The shader writes ordinary materialID0 and reflectance0.5; `BF2-NATIVE-GBUFFER-001` confirms its source metalness and F0 semantics. The native DFG/specular scope may therefore use the final normal and ordinary material model while preserving this distinct SH normal. AO is multiplied once after indirect diffuse.
